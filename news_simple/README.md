# Simplified News Catalyst Trading System

A streamlined trading system that analyzes news sentiment and executes trades based on confidence scores.

## Features

- Real-time news analysis from FMP RSS feed
- Keyword-based sentiment analysis 
- Automated long/short trading decisions
- Stop loss (5%) and take profit (10%) exit strategy
- $10,000 position sizing
- Complete trade logging to CSV
